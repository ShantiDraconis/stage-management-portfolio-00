# Operational scorecard — illustrative methodology

| KPI | Definition | Interpretation |
|---|---|---|
| Open P1 faults | Count severity P1 with status other than VERIFIED/CLOSED | Immediate escalation; never delay safety actions for metrics |
| Open defects | Count tickets not VERIFIED/CLOSED | Outstanding work |
| On-time closure rate | Closed by due date / closed tickets with valid due dates | Requires actual closure timestamp (not included in demo) |
| Preventive maintenance completion | Completed planned checks / due checks | Needs maintenance log |
| Show readiness | Shows passing approved checklist / scheduled shows | Needs verified checklist records |
| Mean time to repair | Sum of verified repair durations / completed repairs | Needs actual start and restoration timestamps |

**Do not report production KPI results from the two synthetic example rows.**
