# show-operations acceptance and handover protocol

1. Scope: approved specification, version, asset list and acceptance criteria.
2. Safety: approved work permit, isolation and access controls as applicable.
3. Physical inspection: labels, routing, condition and installation quality.
4. Configuration: documented patch, firmware, scene/cue or control version.
5. Functional test: test cases with expected and observed outcomes.
6. Defect control: unique ticket, severity, owner, due date and evidence.
7. Retest: independent verification of each resolved defect.
8. Handover: accepted restrictions, fallback plan and responsible role.
